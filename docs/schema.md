# 数据字段规范

每个 `data/benchmarks.json` 记录包含：

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定、唯一、URL 友好的标识 |
| `name` / `year` / `scope` | 基本元数据 |
| `summary` | 评测核心摘要，而非论文摘要复制 |
| `tasks` | 受控任务标签，用于矩阵与筛选 |
| `expert` | 专家来源、经验与质检流程摘要 |
| `rubric` | 评分范式摘要 |
| `access` | 完整开放 / 公开子集 / 仅服务等 |
| `paper` / `data` | 一手论文或项目链接 |
| `demo` | 一条可视化结构样例 |

Demo 的 `rubric` 应满足：一个评分点只判断一件事；措辞可观察；权重反映重要性；避免将写作风格与事实正确性混在同一项。
